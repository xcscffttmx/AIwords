# AI 智能单词本

本目录包含 `AI 智能单词本` 项目的课后作业实现，项目采用前后端分离架构，支持用户注册、登录、单词查询、保存到个人单词本、分页查看和删除记录。

## 项目特点

- 前端使用 Vue3 + Vite + Element Plus
- 后端使用 Go + Gin + GORM
- 数据库存储单词、用户和登录信息
- 支持 DeepSeek 与通义千问两种 AI 提供商
- 查询结果可手动保存到个人单词本
- 删除操作采用软删除，便于数据管理

## 主要功能

1. 用户注册与登录
2. 输入英文单词并调用 AI 生成释义和例句
3. 将查询结果保存到我的单词本
4. 查看和分页管理已保存单词
5. 删除不需要的单词记录

## 目录说明

- `backend/`：后端服务代码
- `frontend/`：前端页面代码
- `docs/`：数据库与接口说明
- `docker-compose.yml`：Docker 编排配置
